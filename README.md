# 📊 Exploratory Data Analysis (EDA) - Titanic Dataset

A Python-based Exploratory Data Analysis (EDA) project that analyzes the Titanic dataset to uncover patterns, understand passenger characteristics, and identify factors influencing survival.

---

## 📌 Project Overview

This project performs data cleaning, preprocessing, and exploratory data analysis on the Titanic dataset. It uses statistical analysis and visualizations to identify trends, relationships, and key insights from the data.

---

## 🚀 Features

- Data Cleaning & Preprocessing
- Missing Value Analysis
- Feature Engineering
- Univariate & Bivariate Analysis
- Correlation Analysis
- Data Visualization
- Statistical Insights

---

## 🛠️ Tech Stack

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📈 Analysis Performed

- Age and gender distribution
- Passenger class analysis
- Correlation analysis
- Feature visualization

---

## 📊 Key Insights

- Female passengers had significantly higher survival rates.
- First-class passengers showed the highest survival probability.
- Younger passengers had better survival chances.
- Passenger class strongly influenced survival outcomes.
